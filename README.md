# Excel-Sales-And-Performance-Analysis
Interactive Excel Dashboard analyzing retail sales metrics, product performance, and revenue trends.

 📈 Excel Sales & Performance Analytics Dashboard

 📌 Project Overview
     This project delivers an interactive Data Analytics dashboard built entirely in Microsoft Excel. 
     It processes raw transactional datasets to evaluate sales performance, key profit metrics,
     regional distribution, and top-selling product categories.

 🛠️ Tools & Excel Functions Used
- **Data Cleaning & Transformation:** Power Query, Text Functions, TRIM, REMOVE DUPLICATES
- **Formulas & Calculations:** XLOOKUP, INDEX-MATCH, SUMIFS, COUNTIFS, IF Statements
- **Data Summarization:** Pivot Tables & Pivot Charts
- **Interactive Controls:** Slicers, Timeline Filters, Conditional Formatting

 🔑 Key Features & Insights
- **KPI Metrics:** Executive summary cards displaying Total Revenue, Total Orders, Average Order Value (AOV), and Profit Margin.
- **Sales Trends:** Time-series analysis identifying monthly and seasonal revenue spikes.
- **Product Analysis:** Category-wise revenue distribution highlighting top 5 revenue-generating items.
- **Dynamic Filtering:** Interactive Slicers allowing region-wise and product-wise deep dives.
